# Tray-Land

Tray-Land brings together Windows system tray apps and macOS menu bar apps: small, purpose-built utilities that stay close at hand without getting in your way.

Each app focuses on a specific task. Together, they form a collection of complementary tools that users can mix and match to make everyday computing simpler.

## What belongs here

- **Windows tray apps** that live in the notification area.
- **macOS menu bar apps** that offer quick access from the menu bar.
- **Focused utilities** that do one thing well, with lightweight interfaces and minimal friction.

The goal is not one large application that does everything, but a family of small apps that work well alongside one another. Use only the tools you need and keep the rest out of your way.

## About this repository

This `.github` repository holds organization-wide documentation and shared community files for Tray-Land. Individual apps live in their own repositories within the organization.
